10.10.1994 CERN

Authors with influence. Readers with control.

Håkon's proposal did not treat design as decoration. It described a negotiation between the person publishing a document and the person reading it.

“The user should have the last word, but one should also allow the author to attach style hints.”

The gift

Thank you for giving the web a language that remains open to everyone.

Every readable layout, personal theme, print sheet, responsive reflow, and carefully chosen color carries the original idea forward: authors can speak, readers can answer, and the document survives.
